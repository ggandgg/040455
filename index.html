① 下載 AHK 腳本（第一次使用先下載到雲端資料夾）

建議在雲端硬碟建立一個資料夾（例如 vitals/），把兩支 .ahk 放進去； 之後每次下載 data.csv 也存到同一個資料夾覆蓋，AHK 會自動讀取。 電腦需安裝 AutoHotkey v1.1。 

vitals/                  ← 你的雲端資料夾（Google Drive / OneDrive / Dropbox 都可）
├─ auto_click.ahk        ← 從這裡下載 ↓
├─ auto_input.ahk        ← 從這裡下載 ↓
└─ data.csv              ← 每次輸入完從表格下載，蓋掉舊的
② 使用步驟
  1. 第一次使用：用上方按鈕下載兩支 .ahk 到雲端 vitals/ 資料夾。
  2. 每次使用：在表格輸入每位病人的生命徵象（空白列自動忽略）。
  3. 按 ⬇ 下載 data.csv，存到 vitals/ 同一個資料夾（同名覆蓋）。
    小技巧：把瀏覽器下載位置設成 vitals/，就不用每次手動搬。
  4. 雙擊 auto_click.ahk，到醫院系統輸入頁：F1 點第 1 列、F2 點最後一列、F3 開始自動點擊定位。
  5. 雙擊 auto_input.ahk，按 F1 開始送資料；F2 暫停、F3 繼續、Esc 停止。
📋 改良版 AHK：自動校準 rowHeight（推薦）

不再寫死 rowHeight := 31。F1 標第 1 列、F2 標最後一列， 腳本會自己讀 data.csv 算出筆數，把列高自動算出來，換解析度／螢幕縮放都不用改。

auto_click.ahk

; ==== 自動校準版：左側欄位定位點擊 ====
CoordMode, Mouse, Screen
SetMouseDelay, 10

startX := ""
startY := ""
endY := ""
running := false

F1::
MouseGetPos, startX, startY
ToolTip 第一列 %startX% , %startY%
Sleep 700
ToolTip
return

F2::
MouseGetPos, , endY
ToolTip 最後一列 Y=%endY%
Sleep 700
ToolTip
return

F3::
if (startX = "" || startY = "" || endY = "")
{
    MsgBox 請先 F1 標第一列、F2 標最後一列
    return
}

; 自動修正上下顛倒
if (startY > endY)
{
    tmp := startY
    startY := endY
    endY := tmp
}

; 從 data.csv 自動讀筆數
FileRead, csv, data.csv
if (ErrorLevel)
{
    MsgBox 找不到 data.csv（請放在腳本同資料夾）
    return
}
StringReplace, csv, csv, `r,, All
rows := StrSplit(csv, "`n")
rowCount := 0
for i, r in rows
    if (Trim(r) != "")
        rowCount++

if (rowCount < 2)
{
    ; 只有 1 筆就直接點一次
    MouseMove, startX, startY, 0
    MouseClick, left
    return
}

rowHeight := (endY - startY) / (rowCount - 1)
ToolTip rowCount=%rowCount%`nrowHeight=%rowHeight%
Sleep 800
ToolTip

running := true
Loop %rowCount%
{
    if (!running)
        break
    y := startY + (A_Index - 1) * rowHeight
    MouseMove, startX, Round(y), 0
    MouseClick, left
    Sleep 30
}
running := false
return

running := false

auto_input.ahk

; ==== 自動輸入 data.csv ====
SendMode Input
SetKeyDelay, -1
SetBatchLines, -1
SetWinDelay, -1

paused := false
stop := false

Esc::
stop := true
paused := false
ToolTip 已緊急停止
Sleep 800
ToolTip
return

F2::
paused := true
ToolTip 已暫停 (按 F3 繼續)
return

F3::
paused := false
ToolTip 繼續輸入
Sleep 500
ToolTip
return

F1::
stop := false
paused := false

FileRead, csv, data.csv
if (ErrorLevel)
{
    MsgBox 找不到 data.csv
    return
}
StringReplace, csv, csv, `r,, All
rows := StrSplit(csv, "`n")

total := 0
for i, r in rows
    if (Trim(r) != "")
        total++

count := 0
for index, row in rows
{
    if (stop)
        break
    while (paused)
        Sleep 50

    row := Trim(row)
    if (row = "")
        continue

    count++
    if (Mod(count, 20) = 0)
        ToolTip 輸入中: %count% / %total%

    fields := StrSplit(row, ",")
    Loop % fields.Length()
    {
        if (stop)
            break
        while (paused)
            Sleep 50

        value := fields[A_Index]
        if (A_Index <= 4)
            SendInput % value . "{Tab}"
        else if (A_Index = 5)
            SendInput % value . "{Tab 2}"
        else if (A_Index = 6)
            SendInput % value . "{Tab 6}"
    }
}

ToolTip 完成輸入 (%count% 筆)
Sleep 1500
ToolTip
return
